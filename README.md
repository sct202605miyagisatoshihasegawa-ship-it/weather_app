# お天気データロガー（世界主要都市）ver2.0

世界の主要都市の天気データ（気温・湿度・気圧）を自動で定期取得し、リアルタイムにグラフ化するJava Swing製のデスクトップアプリケーションです。
特に気象病（頭痛など）の原因となる「気圧の急変動」を自動検知し、ユーザーにアラート（警告表示およびビープ音）で通知する機能を備えています。

## 💡 こだわった技術的ポイント（アピール点）

* **マルチスレッド（非同期処理）による快適なUI操作**
  Java Swingの画面フリーズ（応答なし）を防ぐため、以下の処理を適切なスレッドに分離して完全非同期で実行しています。
  * **データの定期取得**: `ScheduledExecutorService` を用いてバックグラウンドで実行（15分間隔）
  * **画面の描画更新**: Swingのルールに則り、`SwingUtilities.invokeLater` を使用してイベントディスパッチスレッド（EDT）で安全に実行
  * **アラート音声再生**: 連続ビープ音の再生中に画面が止まらないよう、専用の別スレッド（`new Thread()`）を都度立ち上げて処理
* **実戦的なデバッグ・テスト機能の搭載**
  自動取得（15分間隔）の環境下でも即座に判定ロジックの動作検証ができるよう、画面右下に「気圧を強制的に急上昇/急降下させるテストデータ注入ボタン」を実装しました。
* **データの永続化と復元**
  取得したデータはユーザーのデスクトップ上に自動でCSVファイル（`weather_data.csv`）として保存されます。アプリ起動時には、過去のCSVデータを自動読み込みしてグラフを復元する機能を備えています。

## 🛠️ 使用技術・ライブラリ

* **言語**: Java 11 以上（推奨: Java 17）
* **GUIフレームワーク**: Java Swing / AWT
* **グラフ描画ライブラリ**: JFreeChart
* **外部API**: OpenWeatherMap (Current Weather API)

## 🚀 実行・セットアップ手順

### 1. 外部ライブラリ（JFreeChart）の導入
本アプリの実行には `JFreeChart` が必要です。
[※ご自身のプロジェクト環境に合わせて、以下のいずれか片方を残して書き換えてください]

* **Eclipse等でJARファイルを直接配置している場合**:
  JFreeChartの公式ページ等からJARファイルをダウンロードし、プロジェクトの「ビルドパス（Build Path）」に追加してください。
* **Maven / Gradleを使用している場合**:
  pom.xml / build.gradle にJFreeChartの依存関係を追加してください。

### 2. APIキーの設定
1. [OpenWeatherMap](https://openweathermap.org) で無料のアカウントを作成し、APIキー（Current Weather API）を発行します。
2. `WeatherApp.java` の最上部にある定数 `API_KEY` に、発行したご自身のキーを貼り付けてください。
   ```java
   private static final String API_KEY = "ここにあなたのAPIキーを貼り付け";
   ```
   *(※注意: GitHub等に公開する際は、本物のAPIキーをコミットしないようご注意ください。実務を想定し、今後は外部設定ファイルや環境変数から読み込む形式へアップデート予定です)*

### 3. アプリの起動
`WeatherApp.java` を実行すると、メイン画面が立ち上がります。

## 📋 主な機能と使い方

1. **リアルタイムグラフ表示**
   * タブを切り替えることで、「気温」「湿度」「気圧」の推移グラフ（JFreeChart）を確認できます。
2. **表示都市の絞り込み**
   * 画面下部のチェックボックスを外すことで、特定の都市のグラフ線を非表示にできます。
3. **気圧急変動アラート（仙台市が対象）**
   * 仙台の気圧が「過去1時間」と比較して **3.0 hPa 以上** 変動した場合、画面右上に警告テキストが表示され、PCからビープ音が鳴ります（上昇時: 1回、降下時: 3回）。
4. **テストモード**
   * 画面右下の「🧪 テスト: 気圧上昇/降下」ボタンを押すと、即座に判定ロジックが走り、アラート機能（音声とUI変更）の動作テストが行えます。
